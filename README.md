# Get Well Soon, Nancy! 💖

This is a beautiful, interactive single-page website created just for you to bring a smile to your face while you recover. It features sweet messages and some fun little games!

## How to Deploy to GitHub Pages

If you want to put this website on the internet so Nancy can view it from anywhere, follow these easy steps:

### Step 1: Create a GitHub Account (if you don't have one)
1. Go to [GitHub](https://github.com/) and sign up for a free account.

### Step 2: Create a New Repository
1. In the top-right corner of GitHub, click the **+** icon and select **New repository**.
2. Name your repository something like `get-well-nancy`.
3. Make sure it is set to **Public** (so GitHub Pages can host it for free).
4. Do NOT check "Add a README file" (since we already have one).
5. Click **Create repository**.

### Step 3: Upload the Files
1. On the next page, look for the link that says **"uploading an existing file"** (it should be near the top under "Quick setup").
2. Drag and drop all the files from this folder (`index.html`, `styles.css`, `script.js`, and this `README.md`) into the box on the screen.
3. Once they finish uploading, scroll down to "Commit changes", type a message like "Initial commit", and click the green **Commit changes** button.

### Step 4: Enable GitHub Pages
1. In your repository on GitHub, click the **Settings** tab (the gear icon near the top right).
2. On the left sidebar, scroll down and click on **Pages** (under the "Code and automation" section).
3. Under "Build and deployment", look for the **Source** dropdown and select **Deploy from a branch**.
4. Below that, click the branch dropdown (it usually says "None"), select **main** (or **master**), and click **    Save**.
5. Wait a few minutes (usually 1-3 minutes). If you refresh the page, you should see a message at the top saying: **"Your site is live at https://[yourusername].github.io/get-well-nancy/"**.
6. Send that link to Nancy! 💌

## Running Locally

If you just want to view it on your own computer:
1. Open the folder containing these files.
2. Double-click on `index.html`. It will open in your default web browser (like Chrome, Safari, or Edge) and you can play with it right away!
